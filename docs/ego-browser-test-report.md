## 6. 根因定位

**#1 说说页（P1）**
- `src/ui/js/social.js:3` 的 import 列表为 `{ api, confirmDialog, esc, filterRows, fmtDate, icon, openModal, route, setTitle, toast }`，**缺少 `debounce`**；
- 同文件 `:232` 调用 `document.getElementById("search").oninput = debounce(draw, 200)` → `ReferenceError`；
- `src/ui/js/core.js:368-374` 的 `renderRoute` 用 `try/catch` 把异常渲染为「加载失败」视图，因此该错误**不会进入 `pageerror`/console.error**，既有 13 项 UI 冒烟与 K5「零 JS 错误」断言均无法发现它；
- `debounce` 实际导出于 `core.js:68`，`content.js:3` 的 import 是正确参照。
- **最小修复**：在 `social.js:3` 的 import 中补 `debounce`（1 行）。

**#2 弹窗遮罩（P2）**
- `src/ui/js/core.js:350-376` 的 `renderRoute()` 处理 `hashchange` 时不调用 `closeModal()`；
- `openModal()`（`core.js:152`）设置 `root.hidden = false`，`.modal-backdrop` 为全视口覆盖层；`closeModal()`（`:175`）仅由弹窗按钮触发；
- 因此弹窗打开期间所有被遮罩覆盖的元素（含侧栏导航）都不可点，用户被"锁"在当前弹窗内。
- **建议修复**：`renderRoute()` 开头调用 `closeModal()`；并补充 Esc 键与点击遮罩关闭（`core.js` 目前无 keydown/backdrop 绑定）。

**#3 图床前置引导（P3）**
- 图床设置默认 `关闭`（`src/images.ts:20`、`api-app.ts` 的 `IMG_HOST` 默认值）；`renderImages`（`content.js:597`）不读取该状态，始终渲染上传入口；
